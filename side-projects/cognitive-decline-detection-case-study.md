# Cognitive Decline Detection Case Study

## Background

Early identification of cognitive decline is an important research problem with obvious real-world relevance, but it also requires careful handling of data, modelling, and interpretation.

## Problem

I wanted to explore whether machine learning techniques could detect useful signals associated with cognitive decline from language and speech-related features, while also comparing different modelling approaches.

## What I built

I built a machine learning pipeline using the DementiaBank dataset, combining feature engineering and model comparison across classifiers including SVC, XGBoost, and Random Forest. The project also explored BERT-based representations and considered how the work might translate into a clinician-facing support concept.

## Tools used

- Python
- scikit-learn
- XGBoost
- BERT-based embeddings
- NLP / speech-related features
- HPC training workflow

## Users / scale

- Dissertation / research-led project
- Built on a real dataset with structured model comparison
- Designed to explore clinically relevant machine learning use cases

## Outcome

- Achieved around 80% accuracy on the chosen dataset and approach
- Produced a strong applied ML portfolio project
- Strengthened my skills in feature engineering, evaluation, and model comparison

## What I learned

This project reinforced the importance of feature design, careful evaluation, and understanding the limitations of a model in a sensitive problem space. Technical performance is only one part of a useful ML solution.

## What I would improve

I would deepen evaluation across more robust validation strategies, improve interpretability, and explore more carefully how such a system should be positioned in practice.
