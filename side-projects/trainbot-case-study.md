# TrainBot Case Study

## Background

Passenger information is often reactive, fragmented, or difficult to interpret quickly when travel plans change.

## Problem

I wanted to explore whether a lightweight conversational tool could make rail information easier to access while also adding more proactive value through delay prediction features.

## What I built

I built a Python-based rail chatbot that provided live journey information and delay prediction features using real-time transport data. The project combined data retrieval, custom NLP / NER logic, and predictive components to create a more useful passenger-information experience.

## Tools used

- Python
- API integration
- NLP / NER logic
- Regression / predictive modelling
- Real-time transport data

## Users / scale

- Built as a side project / portfolio project
- Designed to explore transport and mobility use cases
- Focused on practical, user-facing functionality

## Outcome

- Created a working transport-focused project combining software, data, and ML concepts
- Strengthened my skills in API integration, NLP, and predictive thinking
- Produced a memorable project aligned to transport and mobility roles

## What I learned

This project showed how much value comes from combining multiple technical disciplines into something practical. It also reinforced the importance of designing around user questions rather than just raw data access.

## What I would improve

I would add a cleaner front end, stronger handling of uncertain or ambiguous inputs, and more robust model evaluation for prediction quality.
