# Tech Review Minutes Automation

## Background

A manual process for handling technical review minutes was consuming most of one colleague's time and limiting capacity for more valuable work.

## Problem

Meeting actions, notes, and follow-up were being handled in a way that depended heavily on manual effort. This made the process slow, repetitive, and harder to scale or standardise.

## What I built

I developed a Power Platform solution to automate and structure the capture, management, and follow-up of technical review minutes. The aim was to make the process easier to manage, reduce admin overhead, and improve consistency.

## Tools used

- Power Apps
- Power Automate
- SharePoint / Dataverse
- Microsoft 365

## Users / scale

- Used by internal technical review stakeholders
- Primary day-to-day user was the colleague previously managing the process manually
- Designed to support repeatable meeting workflows and follow-up activity

## Outcome

- Reduced admin workload by approximately 25 hours per week
- Improved consistency in how technical review minutes were captured and followed up
- Freed up time for higher-value work

## What I learned

This project showed the value of focusing on a clear operational bottleneck and solving it with a structured, usable workflow. It also reinforced how small internal tools can create disproportionate value when they remove repetitive manual work.

## What I would improve

I would add stronger reporting around outstanding actions, turnaround times, and process bottlenecks, plus a cleaner audit trail of follow-up activity.
