# Technical Case Studies

A small portfolio of anonymised case studies based on internal tools, analytics, workflow automation, and operational software projects.

## About

This repository showcases the kind of technical and operational problems I enjoy solving: improving messy processes, building useful internal tools, and turning complex data into clearer decisions.

The projects here are anonymised where needed, but each case study reflects real delivery experience across analytics, workflow automation, internal tooling, and decision-support systems.

## What these case studies show

- Building internal tools people actually use
- Turning fragmented processes into structured workflows
- Using data and automation to improve visibility, accountability, and speed
- Designing solutions that support day-to-day operational decisions
- Balancing technical delivery with stakeholder needs and adoption

## Case studies

### 1. [Change Management Platform](change-management-platform.md)
Power Platform-based internal tooling to centralise and improve change-management workflows across operational teams.

### 2. [Build Complexity Analytics](build-complexity-analytics.md)
Decision-support analytics to help stakeholders assess cost, weight, and complexity trade-offs across engineering variants.

### 3. [Tech Review Minutes Automation](tech-review-minutes-automation.md)
Workflow automation solution to reduce manual admin effort and improve follow-up from technical review meetings.

### 4. [Engineering Release Improvement](engineering-release-improvement.md)
Analytics and process improvements that strengthened release control and improved engineering release performance.
