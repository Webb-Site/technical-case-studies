# Technical Case Studies

A portfolio of anonymised case studies covering internal tools, analytics, workflow automation, operational improvement, and applied side projects.

## Start here

This repository is designed to show **how I approach real technical problems**:

- turning fragmented or manual processes into structured tools
- building analytics that support better decisions
- improving visibility, accountability, and operational speed
- combining software, automation, and data skills in practical ways

Most examples are based on real delivery experience in enterprise environments, so implementation detail is anonymised where needed. The focus here is on the **problem**, **approach**, **tools**, **scale**, **outcome**, and **what I learned**.

## Case study format

Each case study follows the same structure:

- Background
- Problem
- What I built
- Tools used
- Users / scale
- Outcome
- What I learned
- What I would improve

That consistency is deliberate. I want the focus to be on the quality of the problem-solving, not just the technology names.
